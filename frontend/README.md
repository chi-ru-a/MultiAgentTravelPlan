# Travel Agent Frontend

旅行规划多Agent系统前端项目。

## 技术栈

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Zustand (状态管理)
- Axios (HTTP客户端)

## 安装

```bash
npm install
```

## 开发

```bash
npm run dev
```

访问 http://localhost:3000

## 构建

```bash
npm run build
```

## 预览构建结果

```bash
npm run preview
```

## 配置

创建 `.env` 文件配置API地址：

```bash
VITE_API_URL=http://localhost:8000/api/v1
```
